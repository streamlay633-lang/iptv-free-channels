📺 Free IPTV Channels

A curated collection of free and publicly available television channels in M3U/M3U8 playlist format.

The project is designed for compatible IPTV applications and media players that support M3U/M3U8 playlists.

✨ Features
Free and publicly available channels
Standard M3U/M3U8 playlist format
Simple playlist URLs
Compatible with M3U/M3U8-supported applications
Regular playlist maintenance
Organized channel listings

▶️ Compatibility

The playlists are compatible with applications and platforms that support M3U/M3U8 playlists, including:

IPTV platforms
VLC Media Player
Smart TV applications
Android IPTV applications
iOS IPTV applications
Desktop media players
Other M3U/M3U8-compatible applications

📖 How to Use
Copy the playlist URL.
Open an IPTV application or media player that supports M3U/M3U8 playlists.
Select the option to add a network, remote, or M3U playlist.
Paste the playlist URL.
Load the playlist and select an available channel.
📄 Playlist Format

The playlists use the standard M3U/M3U8 format and are intended for use with compatible IPTV players and applications.
