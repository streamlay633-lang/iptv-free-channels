📺 Free IPTV Channels

A curated collection of free and publicly available television channels in M3U/M3U8 playlist format.

The project is designed for compatible IPTV applications and media players that support M3U/M3U8 playlists.

✨ Features
- 🆓 Free and publicly available channels
- 📄 Standard M3U/M3U8 playlist format
- 🔗 Simple playlist URLs
- 📱 Compatible with M3U/M3U8-supported applications
- 🔄 Regular playlist maintenance
- 📋 Organized channel listings

▶️ Compatibility

The playlist is compatible with applications and platforms that support M3U/M3U8 playlists, including:

- 📺 IPTV platforms
- 🎬 VLC Media Player
- 📺 Smart TV applications
- 🤖 Android IPTV applications
- 🍎 iOS IPTV applications
- 💻 Desktop media players
- 🔌 Other M3U/M3U8-compatible applications

📖 How to Use?

1 -📋 Copy the playlist URL.
2 -📱 Open an IPTV application or media player that supports M3U/M3U8 playlists.
3 -🔗 Select the option to add a network, remote, or M3U playlist.
4 -📥 Paste the playlist URL.
5 - ▶️ Load the playlist and select an available channel.
6 -📄 Playlist Format

The playlist uses the standard M3U/M3U8 format and is intended for use with compatible IPTV players and applications.

🔄 Updates

The playlist is maintained regularly. Channels may be added, removed, or updated when necessary.

If you encounter an unavailable channel or an incorrect playlist entry, please report the issue so it can be reviewed.
