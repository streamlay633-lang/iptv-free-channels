# 📺 Free IPTV Channels
A collection of publicly available IPTV channels and M3U playlists for watching live TV on supported devices.

✨ Features
- 🌍 Channels from around the world
- 📡 M3U and M3U8 playlist support
- 📺 Multi-platform compatibility
- 🔄 Community contributions
- 🆓 Free-to-access streams where legally available
- 📺 Supported Platforms
- 🪟 Windows
- 🍎 macOS
- 🐧 Linux
- 🤖 Android
- 📱 iOS and iPadOS
- 📺 Android TV and Google TV
- 🍏 Apple TV (tvOS)
- 📺 Samsung Smart TV
- 📺 LG Smart TV
- 🔥 Amazon Fire TV

Compatibility depends on the IPTV player and device.

▶️ How to Use
1. Install an IPTV player that supports M3U playlists.
2. Copy a playlist URL from this repository.
3. Add the URL to your IPTV player.
4. Load the playlist and watch available channels.
